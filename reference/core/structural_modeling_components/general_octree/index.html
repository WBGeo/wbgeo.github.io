    General octree

    Structural modeling on an :class:OctreeGrid.

    The octree counterpart of :func:general.compute_structural_model, which dispatches here when the frame's grid is an OctreeGrid:

    1) Fit each group's scalar field once (fit_group_*), or with faults once per group and merged fault-domain component. 2) Refine the octree where the lithology or any group's own surfaces change between cell corners. This octree resolves every surface, including the parts eroded by younger groups, which surface meshes need. With faults, refinement starts from the fault frame's cells, every cell keeps the domain of the fault cell it lies in, and points are evaluated with the field of their cell's domain. 3) Extract the UNMASKED, MASKED and EXTENDED surface meshes of every element by dual contouring on the refined octree, per merged fault-domain component (contoured once, for EXTENDED; UNMASKED and MASKED are taken from it). MASKED keeps a quad only if none of its 4 cells is eroded by a younger group, and of that only the triangles whose vertices are not eroded themselves; EXTENDED also runs on a max-level shell around the extent, so it crosses the model box. EXTENDED_MASKED is one piece per component, contoured with the component's field on its cells plus a band into the neighbouring domains, and kept up to a small overshoot past its faults and the base of the younger groups. COMBINED contours the lithology id itself. 4) Coarsen back to the cells the stored result needs: merge cells wherever the final model doesn't change, so the result keeps as few cells as possible. That is: the lithology and the age masks are the same, and no fault that affects the group present there separates the cells (cells on both sides of a fault that the present group ignores do merge). With grid.cell_balance the stored cells are 2:1 balanced afterwards. 5) Evaluate fields, age masks and lithology at the final cell centers and store them in the usual attributes, one value per cell (see StructuralFrame). 6) With faults, the MASKED and EXTENDED_MASKED meshes of every fault: its UNMASKED triangles where the youngest group the fault does not affect is absent, and its EXTENDED triangles below the base of every group younger than the youngest group it affects, plus a small overshoot.

    Current scope: interpolators listed in fit_dispatch; all surface mesh types. The domain components, their fit extents, the age mask and lithology rules are the pointwise equivalents of run_interpolation_with_fault_domains, set_scalar_masks_per_domain and compute_lithology_block_with_domains.

    def compute_structural_model_octree(
        frame: StructuralFrame,
        *,
        extract_meshes: bool = True,
) -> StructuralModelResults:
    """
    Compute a structural model on the frame's OctreeGrid.

    Parameters
    ----------
    frame : StructuralFrame
        Frame with an OctreeGrid, groups, elements and input data, as built by
        ``build_structural_frame``, optionally with a fault frame computed on the
        same grid.
    extract_meshes : bool, default True
        Extract each element's UNMASKED, MASKED, EXTENDED, EXTENDED_MASKED and
        COMBINED surface meshes by dual contouring, and each fault's MASKED and
        EXTENDED_MASKED meshes.

    Returns
    -------
    StructuralModelResults
        A deep copy of the frame with ``cells`` set and, per cell, every group's
        ``scalar_field`` and ``mask`` and the ``lith_block``.

    Raises
    ------
    NotImplementedError
        If a group uses an interpolator that has no fit/evaluate implementation yet.
    ValueError
        If an attached fault frame is not on the same OctreeGrid or has no cells,
        or if the fits of a group's domain components disagree on an element's
        scalar value.
    """
    grid = frame.grid
    if not isinstance(grid, OctreeGrid):
        raise TypeError(f"compute_structural_model_octree needs an OctreeGrid, got {type(grid).__name__}.")
    ff = frame.fault_frame
    if ff is not None and (ff.grid != grid or ff.cells is None or ff.domain_map is None):
        raise ValueError(
            "The fault model must be computed on the same OctreeGrid as the structural model. "
            "Connect the same grid to both, or recompute the fault model on this grid."
        )
    unsupported = [f"'{g.name}' ({g.interpolation_method})" for g in frame.structural_groups
                   if g.interpolation_method not in fit_dispatch]
    if unsupported:
        raise NotImplementedError(
            "On an OctreeGrid only these interpolators are available so far: "
            f"{', '.join(m.value for m in fit_dispatch)}. Groups using others: {', '.join(unsupported)}."
        )
    if not frame.structural_groups:
        raise ValueError("The structural frame contains no groups.")

    _assign_element_ids(frame)

    logger.info("Fitting scalar fields ...")
    fields = _fit_groups(frame)

    logger.info("Refining the octree ...")
    mesh_cells = _refine_for_surfaces(frame, fields)

    if extract_meshes:
        logger.info("Extracting surface meshes by dual contouring ...")
        _extract_element_meshes(frame, fields, mesh_cells)

    logger.info("Coarsening the octree for the stored result ...")
    cells = _coarsen_for_storage(frame, fields, mesh_cells)
    logger.info(
        "Octree cells: %d refined for surfaces, %d stored (equivalent regular grid: %d).",
        len(mesh_cells), len(cells), int(np.prod(grid.finest_resolution)),
    )

    logger.info("Evaluating the model at cell centers ...")
    centers = cells.centers(grid)
    domains = _point_domains(frame, centers)
    values = _evaluate_groups(frame, fields, centers, domains)
    lith, masks = _lithology_and_masks(frame, values, domains)

    frame.cells = cells
    for group_idx, group in enumerate(frame.structural_groups):
        group.scalar_field = values[group_idx]
        group.mask = masks[group_idx]
        group.extended_scalar_field = None
    frame.lith_block = lith
    frame.check_cell_arrays()

    if extract_meshes and frame.fault_frame is not None:
        _extract_fault_masked_meshes(frame, fields, masks)

    return StructuralModelResults(structural_frame=copy.deepcopy(frame))

    def fit_extent(grid: OctreeGrid) -> Extent6:
    """The grid's extent padded by ``_FIT_PADDING_CELLS`` finest cells on every side."""
    pad = _FIT_PADDING_CELLS * grid.finest_spacing
    lower = np.array(grid.extent[0::2]) - pad
    upper = np.array(grid.extent[1::2]) + pad
    return tuple(float(v) for pair in zip(lower, upper) for v in pair)
