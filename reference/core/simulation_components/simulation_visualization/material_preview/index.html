    Material preview

    Pre-flight material preview for SfePy and GOLEM problem builders.

    Before a (possibly slow) solve, plot_builder_materials shows which material each mesh cell gets, either one colour per material or coloured by a numeric material property. Every builder type is first reduced to the same description (_MaterialLayout: a grid, the material of each cell and each material's literal property values); colours, legend and plotter setup are then shared by both simulators.

    Colours follow the structural model: a rock material that belongs to a lithology gets that StructuralElement's colour (basement grey), as in plot_structural_model_3D and plot_mesh_3d. Faults, fractures and wells get fixed colours that no lithology uses and are drawn opaque, so they stay visible inside the semi-transparent rock.

    plot_builder_materials(builder, style='surface', show_edges=False, show_plotter=True, property_name=None, cmap='viridis', opacity=0.65)

    Preview the material assignment of a SfePy or GOLEM problem builder.

    Works for SfepyHydrothermalProblemBuilder, SfepyCustomBuilder, GolemHydrothermalProblemBuilder, GolemCustomBuilder and GolemSimpleReservoirBuilder, with the same colours, legend and view for all of them.

    Without property_name, every material gets one colour: lithologies their structural-model colour, faults (SfePy damage zones and GOLEM 2D fault blocks), fractures and wells fixed opaque colours. The legend is grouped like the structural model plot's.

    With property_name, cells are coloured by that literal material value (for example "porosity", "k_solid", or a custom file's own coefficient names). Fluid properties are shared by all materials and can be given as "fluid." or as "viscosity", "mu", "rho_c_fluid" and similar. Expression- or state-dependent values can't be previewed before a solve.

    :param builder: The problem builder to preview. :param style: PyVista style of the material meshes ("surface", "wireframe", ...). :param show_edges: Draw cell edges (noisy above roughly 50k cells). :param show_plotter: Show the window; False renders off screen and only returns the plotter. :param property_name: Numeric material property to colour by; None for one colour per material. :param cmap: Colormap for property_name. :param opacity: Opacity of rock materials (faults, fractures and wells are drawn opaque). :return: The PyVista plotter.

    def plot_builder_materials(
    builder,
    style: str = "surface",
    show_edges: bool = False,
    show_plotter: bool = True,
    property_name: Optional[str] = None,
    cmap: str = "viridis",
    opacity: float = 0.65,
) -> pv.Plotter:
    """Preview the material assignment of a SfePy or GOLEM problem builder.

    Works for SfepyHydrothermalProblemBuilder, SfepyCustomBuilder,
    GolemHydrothermalProblemBuilder, GolemCustomBuilder and
    GolemSimpleReservoirBuilder, with the same colours, legend and
    view for all of them.

    Without property_name, every material gets one colour: lithologies their
    structural-model colour, faults (SfePy damage zones and GOLEM 2D fault
    blocks), fractures and wells fixed opaque colours. The legend is grouped
    like the structural model plot's.

    With property_name, cells are coloured by that literal material value
    (for example "porosity", "k_solid", or a custom file's own coefficient
    names). Fluid properties are shared by all materials and can be given
    as "fluid.<name>" or as "viscosity", "mu", "rho_c_fluid" and similar.
    Expression- or state-dependent values can't be previewed before a solve.

    :param builder: The problem builder to preview.
    :param style: PyVista style of the material meshes ("surface", "wireframe", ...).
    :param show_edges: Draw cell edges (noisy above roughly 50k cells).
    :param show_plotter: Show the window; False renders off screen and only returns the plotter.
    :param property_name: Numeric material property to colour by; None for one colour per material.
    :param cmap: Colormap for property_name.
    :param opacity: Opacity of rock materials (faults, fractures and wells are drawn opaque).
    :return: The PyVista plotter.
    """
    layout = _material_layout(builder)
    if property_name is None:
        return _plot_materials(layout, style=style, show_edges=show_edges,
                               show_plotter=show_plotter, opacity=opacity)
    return _plot_property(layout, property_name, style=style, show_edges=show_edges,
                          show_plotter=show_plotter, cmap=cmap, opacity=opacity)
